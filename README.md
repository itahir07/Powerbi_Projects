# 🏪 Amazon Superstore Dashboard

> Power BI dashboard providing comprehensive sales performance analysis for the Amazon Superstore dataset, featuring regional breakdowns, product category insights, and profitability metrics.

## 🎯 Project Objectives

- Analyze **sales performance** across product categories and sub-categories
- Identify **regional trends** and top-performing states
- Track **profitability metrics** by segment and category
- Discover **seasonal sales patterns** and peak periods
- Evaluate **shipping mode efficiency** and delivery performance

## 🛠️ Tools & Technologies

| Tool | Purpose |
|------|--------|
| **Power BI Desktop** | Dashboard design & interactive visualizations |
| **DAX** | Calculated measures, KPIs & dynamic calculations |
| **Power Query (M)** | Data cleaning, transformation & modeling |

## 📊 Dashboard Features

- **Sales Overview** — Total sales, profit, quantity, and discount KPIs
- **Regional Analysis** — Sales distribution across regions and states
- **Category Breakdown** — Performance by product category and sub-category
- **Customer Segments** — Consumer, Corporate, and Home Office analysis
- **Time Series** — Monthly and yearly trend analysis

## 🚀 Getting Started

1. Download `reports/Amazon_Superstore_Dashboard.pbix`
2. Open with [Power BI Desktop](https://powerbi.microsoft.com/desktop/)
3. Refresh data connections if prompted
4. Interact with visualizations using filters and slicers
